# Security policy

This is prerelease software, currently a read-only monitor and simulator. It has
not undergone independent security review. Do not use it as a safety interlock.

There is no published project or private vulnerability-reporting channel yet.
Before publishing, the maintainer must enable GitHub private vulnerability
reporting and replace this paragraph with the project's exact reporting URL.
Do not post credentials, BIOS passwords, serials or exploit details in public issues.

Only the current prerelease is maintained. A production security-support window,
response owner and disclosure process must be established before stable release.
See [report.md](report.md) for threats, existing mitigations and missing protections.
